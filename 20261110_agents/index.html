Performance by trip number

Each agent keeps its own map and landmarks between trips. If what it learned helps, later trips are quicker, use less energy and break fewer rules. Violation seconds are measured against the rule layer the agent did not know at first (off its band, inside a no-fly zone, against a lane).

    How to read it

    • City + rules: a simplified, simulated Manhattan (street grid, Central Park, Midtown and Downtown towers), the one-way river loop (chevrons), no-fly zones (red: everyone, violet: drones only), heliports (yellow rings), rooftop drone pads (cyan; hubs larger), band signs (white posts).
    • One agent's map: only what the selected agent knows: cells it has seen (land, water), blocks for obstacles (red when too tall for its band), lanes and no-fly zones it has found, its landmarks (coloured dots) with a thin line to what each is remembered against: home for a drone, a visual reference for a helicopter.
    • Everyone together: all paths overlaid, congestion landmarks as spheres, and a heat map on the ground.
